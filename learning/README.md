# Общая память обучения

Эта папка — единственный источник правды о том, как идёт обучение Богдана по курсу math-for-ai-2026. С ней работают два агента:

- **Claude Code** — в IDE, на этом репозитории;
- **nanoclaw** — в мессенджере.

Богдан может начать тему с одним агентом и продолжить с другим, поэтому оба читают и пишут одни и те же файлы.

## Файлы

| Файл | Что в нём | Кто меняет |
|---|---|---|
| `README.md` | этот протокол | только по просьбе Богдана |
| `progress.md` | где сейчас, план, слабые места, хвосты, журнал сессий | оба агента, после каждой задачи |
| `tutor-rules.md` | как вести занятия: педагогика и предпочтения Богдана | оба агента, когда Богдан даёт новое правило |
| `../practice/<модуль>/<задача>.ipynb` | ноутбук задачи с саммари | Claude Code (nanoclaw — при наличии доступа к файлам) |
| `../.claude/skills/math-tutor/SKILL.md` | базовый метод репетитора (сократический) | только по просьбе Богдана |

Решения задач лежат в `../PRACTICE.md` и в `<details>` блоках `../BASICS.md`. Их читаешь только ты, сам — не цитируй и не пересказывай (см. `SKILL.md`).

## Протокол сессии

### В начале
1. `git pull --rebase origin main`
2. Прочитай `tutor-rules.md`, `progress.md` (раздел «Сейчас» и последние 3–5 записей журнала) и `../.claude/skills/math-tutor/SKILL.md`.
3. Скажи Богдану одной строкой, где он остановился и что дальше по плану.

### Во время
- Ведёшь занятие по `SKILL.md` и `tutor-rules.md`.
- Теорию для задачи берёшь из `../modules/*.md` и `../BASICS.md`. Если для задачи нужна формула, которой в теории курса нет, — дай её явно и скажи, что в курсе её нет.

### После каждой закрытой задачи (и в конце сессии, даже если задача не закрыта)
1. Обнови `progress.md`:
   - раздел **«Сейчас»** — текущая задача, следующий шаг;
   - **«Слабые места»** / **«Хвосты»** — добавь или закрой пункты;
   - **«Журнал»** — новая запись сверху, формат ниже.
2. Если Богдан дал новое правило ведения занятий — допиши в `tutor-rules.md`.
3. Коммит и push:
   ```bash
   git add learning/ practice/
   git commit -m "learning: <агент> — <что сделано>"   # агент: claude-code | nanoclaw
   git push origin main
   ```
4. Если push отклонён: `git pull --rebase origin main`, при конфликте в `progress.md` **оставь записи обоих агентов** (журнал — объединить по датам, «Сейчас» — взять более свежее), потом push.

### Формат записи журнала

```markdown
### 2026-10-20 · claude-code · Б12
- Решено: Б12.1–Б12.3. Саммари: practice/basics/Б12.ipynb
- Затыки: <коротко, по существу — что путал>
- Что помогло: <приём, который сработал>
- Дальше: <следующий шаг>
```

Пиши факты, а не оценки. Одна запись — одна сессия или одна задача.

## Особенности каналов

- **Мессенджер (nanoclaw):** LaTeX не рендерится. Формулы пиши юникодом: `x² < 9`, `√2`, `σ(z)`, `∀ε > 0`, `|aₙ − L| < ε`, дроби — `a/b` или `(a + b)/(c − d)`.
- **IDE (Claude Code):** работает только простой inline LaTeX `$…$`. Многострочный (`$$…$$`, `\text`, `\lvert`, `pmatrix`) у Богдана в чате часто не рендерится — проверяй, при сомнениях юникод. В ноутбуках LaTeX рендерится полностью.
- Код и ноутбуки — в IDE. В мессенджере задачи решаются на словах и числах; если нужен ноутбук, оставь хвост «проверить в ноутбуке».

## Репозиторий

- `origin` — форк `ziliboba-dev/math-for-ai-2026`, сюда пишем.
- `upstream` — оригинальный курс `justxor/math-for-ai-2026`, только чтение. Обновления курса: `git pull upstream main` — только по просьбе Богдана.
- Форк **публичный**: не пиши в `learning/` ничего, что Богдан не хотел бы показать.

## Подключение nanoclaw

1. Дай агенту доступ к репозиторию: клон внутри его рабочей папки или примонтированная папка с этим репо, плюс GitHub-токен с правом `repo` на форк.
2. Добавь в `CLAUDE.md` группы, где идёт обучение:

   ```markdown
   ## Обучение математике
   Репозиторий: <путь к клону math-for-ai-2026>.
   Когда Богдан говорит про курс, задачу, модуль, BASICS или «продолжим учёбу» —
   работай по протоколу из learning/README.md (pull в начале, обновить progress.md и push в конце).
   ```
